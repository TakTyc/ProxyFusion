# ⚡ ProxyFusion — миллиард живых MTProto-прокси для Telegram

[![Open in Browser](https://img.shields.io/badge/открыть_в_браузере-ProxyFusion-blue?style=for-the-badge)](https://твой-username.github.io/ProxyFusion)

Одностраничное веб-приложение, которое в реальном времени собирает **актуальные MTProto-прокси** из публичных GitHub-репозиториев и позволяет подключиться к Telegram в один клик.

---

## 🚀 Возможности

- 🔄 Загрузка свежих списков прокси с нескольких доверенных GitHub-источников
- 🎲 Вывод случайного прокси в формате `https://t.me/proxy?...`
- 📋 Копирование ссылки в буфер обмена
- 🌐 Кликабельная ссылка — тапни и сразу перейди в Telegram
- 🌍 Поддержка русского и английского языков
- 🌙 Тёмная тема
- 🔁 Автообновление списка каждые 30 минут
- 📊 Счётчик доступных прокси и название активного источника
- 💖 Блок с реквизитами для доната и кнопка связи с автором
- 📱 Полностью адаптивный интерфейс (mobile-first)

---

## 📦 Как использовать

1. **Открой страницу**  
   Перейди по ссылке на GitHub Pages или просто открой локальный файл `index.html` в любом браузере.

2. **Нажми «Получить прокси»**  
   Приложение загрузит последний список прокси с GitHub и покажет случайный.

3. **Нажми на ссылку**  
   Кликни прямо по появившейся ссылке — Telegram откроется автоматически.  
   *Или скопируй её и вставь в настройки прокси (Тип → MTPROTO).*

4. **Не работает?**  
   Нажми «Другой» или «Обновить», чтобы получить другой прокси или свежий список.

# ⚡ ProxyFusion — Millions of Live MTProto Proxies for Telegram

[![Open in Browser](https://img.shields.io/badge/open_in_browser-ProxyFusion-blue?style=for-the-badge)](https://your-username.github.io/ProxyFusion)

A single‑page web application that fetches **up‑to‑date MTProto proxies** from public GitHub repositories in real time and lets you connect to Telegram with a single tap.

---

## 🚀 Features

- 🔄 Fetches fresh proxy lists from multiple trusted GitHub sources
- 🎲 Displays a random proxy in `https://t.me/proxy?...` format
- 📋 One‑click copy to clipboard
- 🌐 The link is clickable — tap it to open Telegram instantly
- 🌍 Supports **Russian** and **English** languages
- 🌙 Dark theme
- 🔁 Auto‑refresh every 30 minutes
- 📊 Shows the number of available proxies and the active source
- 💖 Donation block and direct link to the author’s support chat
- 📱 Fully responsive, mobile‑first design

---

## 📦 How to use

1. **Open the page**  
   Visit the GitHub Pages link or open the local `index.html` file in any browser.

2. **Press «Get Proxy»**  
   The app downloads the latest proxy list from GitHub and shows a random one.

3. **Tap the link**  
   Tap the displayed link — Telegram will open automatically.  
   *Alternatively, copy the link and paste it into Telegram’s proxy settings (Type → MTPROTO).*

4. **Not working?**  
   Press «Another» or «Refresh» to try a different proxy or load a fresh list.
